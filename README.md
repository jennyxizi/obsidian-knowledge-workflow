# Obsidian 知识库工作流

这是一个**可跨智能体使用的 Obsidian 知识库技能**。它把 **Obsidian CEO Steph Ango（kepano）的个人使用经验**融入一套工作流，帮助你从零搭建知识库、从历史对话中提炼结论，或优化已有库。方法来源见 [How I use Obsidian](https://stephango.com/vault)。

## 适用场景

| 你现在的情况 | 这个技能能帮你做什么 |
| --- | --- |
| 刚开始用 Obsidian，还没想清楚要记什么 | 先选两三个实际任务，确定首批笔记和最小目录结构。 |
| 想让 AI 更了解你、你的业务和判断方式 | 整理个人背景、稳定偏好、业务和项目，并建立 AI 阅读入口。 |
| 有价值的信息散落在 ChatGPT 或其他 AI 的历史对话里 | 用配套提示词提取结论，核对后合并到 Obsidian 对应笔记。 |
| 已有知识库，但项目状态难找、笔记之间缺少联系 | 补上项目与决策的链接，按需要加入 Bases 总览或周复盘模板。 |

## 技能怎样用到 Steph Ango 的经验

- **按用途建立最小结构。** 先确定希望知识库解决什么问题，再用少量页面起步，让分类随使用逐步形成。
- **用链接和常青笔记复用判断。** 从项目页链接到相关决策，能跨项目复用的判断用一句结论命名。
- **用模板和属性减少维护。** 有跨项目查看状态的需求时，用 Obsidian Bases 从项目笔记生成总览。
- **定期回顾并写回结论。** 用每周行动清单安排工作，把有长期价值的新结论更新到原笔记。

这些做法已写入 [SKILL.md](SKILL.md) 的实际工作步骤，详细取舍见 [Steph Ango 方法指南](references/steph-ango.md)。

## 怎么用

**复制下面整段，直接发给你的 AI。** 用途还没想清楚也可以直接发，AI 会先问你希望知识库帮你完成什么。有现成的笔记、知识库路径或对话摘录，可以一起提供。

```text
请用下面的 Obsidian 知识库工作流，帮我搭建或优化我的知识库。

技能说明：https://github.com/jennyxizi/obsidian-knowledge-workflow/blob/main/SKILL.md

1. 先问我希望知识库帮我完成什么，用两三个真实任务确认它怎样才算有用。如果我已经说清楚了，就直接沿用。
2. 根据用途收集必要背景、已有笔记和项目资料。给我一份最小结构方案，写清准备建哪些页面、每页有什么用。等我确认结构后再搭建。
3. 把现有资料提炼成对未来有用的最终结论，合并到对应笔记。重要决策保留理由和重评条件，来源集中记录。如果还需要从其他 AI 补充历史信息，请给我一段可以直接发过去的提取提示词。
4. 用第一步的真实任务试跑。根据遇到的问题，再补入口、内部链接、模板或项目总览。
5. 如果你能访问我授权的知识库，就直接在库里执行确认过的方案。如果你只有对话能力，就给我目录清单、每份 Markdown 的路径和可直接保存的正文。

如果你打不开技能链接，以上五步也足以开始。现在先从确认用途开始。
```

有现成的库、只想处理一项任务时，可以复制下面对应的一段。

**整理历史对话**

```text
请读我提供的历史对话，把对未来有用的最终结论合并进现有 Obsidian 笔记。保留稳定偏好、业务定位、项目关键状态、重要决策和可复用经验。重要决策写清选择、理由和重评条件。来源和会影响判断的未知项集中放在末尾。请先列出准备更新的笔记，然后在授权范围内执行。无法写入时，给我可直接保存的 Markdown。
```

**优化已有知识库**

```text
请先读我现有的 Obsidian 入口页、项目页和维护规则，找出最影响实际使用的三个问题。给我一份具体的调整清单，等我确认后再执行。优先利用现有笔记，用内部链接连接项目和判断；只有我确实需要按状态看跨项目总览时，再建议使用 Bases。
```

如果你的 AI 支持加载 `SKILL.md` 技能，可先加载整份目录，再发送上面的提示词。直接粘贴提示词也能开始。

## 工作流程

1. 确认知识库的用途，用两三个实际任务描述它怎样才算有用。
2. 收集与用途有关的背景和现有资料。
3. 确认最小结构后搭建，目录按实际需要决定。
4. 从对话和资料中提炼长期有用的最终结论，合并进对应笔记。
5. 用真实任务试跑，再按需要补充链接、模板、项目总览或周复盘。

如果资料分散在其他 AI 里，可以把[历史对话提取提示词](references/history-extraction-prompt.md)中的用途和任务填好，再复制过去。把提取结果交给负责维护知识库的智能体核对和整理。
